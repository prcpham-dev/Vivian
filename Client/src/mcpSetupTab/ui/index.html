Connecting Vivian to External AI Agents

Use Vivian's structural graph tools directly inside your favorite MCP-compatible AI agent.

⚠️ Scan your workspace first.
Vivian's MCP tools read from a pre-built graph cache. Before your agent can use any tool, you must open the Vivian Graph panel in VS Code and click Scan to generate the graph for your workspace. Without this step, all MCP tool calls will return an error.

1. Copy Configuration

Vivian automatically generates the exact JSON configuration block needed to connect your agent to the FastMCP server.

Option A: VS Code Extension

Use this if you installed Vivian from the extension marketplace or a packaged VSIX.

Option B: GitHub Clone / Dev Mode

Use this if you cloned the Vivian repository and are running or developing the codebase locally.

2. Manually Paste into your Agent

Paste the copied JSON block manually into your agent's MCP settings configuration file. Vivian cannot write to external agent config files automatically — this step is always done by you.

  • Cursor IDE: Open Settings (Gear icon) → Features → MCP. Click + Add new MCP server (Type: Command).
  • Antigravity IDE: Paste it inside ~/.gemini/antigravity-ide/mcp_config.json.
  • Claude Desktop: Open Settings → Developer → Edit Config, and paste inside mcpServers.

3. Grant Tool Permissions

The first time an agent calls a Vivian tool it will show a permission prompt — click Approve or Always Allow. To skip this every session, write a global rules file that tells any AI agent to auto-request Vivian permissions on startup.

This writes to ~/.gemini/config/AGENTS.md. Any AI agent that reads that directory will automatically request Vivian MCP permissions — no per-project setup needed.

4. Restart your IDE / Session

After pasting the configuration and setting up rules, restart your IDE or start a new agent chat session to load the new tools and permissions rules.
